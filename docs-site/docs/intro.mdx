Heros-SOS met en relation des citoyens qui signalent un incident et des super-héros qui le prennent en
charge, sous la surveillance de modérateurs. Ce site rassemble la documentation technique du projet.

## Ce que contient le site

| Section                                                  | Contenu                                                                                                      |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| <Link to="/architecture">Architecture</Link>             | Qui parle à qui (proxy, front, API, base, services externes) et le déroulé d'une connexion, en schémas.      |
| <Link to="/backend/MVP">MVP</Link>                       | Le périmètre de la première version, le scénario de démonstration et ce qui est reporté.                     |
| <Link to="/backend/STACK">Stack</Link>                   | Les choix techniques du backend : une page par sujet (Go, PostgreSQL, Docker, OpenAPI, sécurité, sessions…). |
| <Link to="/backend/TABLES">Tables</Link>                 | Le schéma de la base de données : une page par domaine, table par table.                                     |
| <Link to="/api/heros-sos-api">API</Link>                 | Le contrat de l'API REST, une page par opération, avec les schémas et des exemples.                          |
| <Link to="/fonctionnement">Fonctionnement du site</Link> | D'où viennent les pages, comment lancer le site et comment en ajouter une.                                   |
